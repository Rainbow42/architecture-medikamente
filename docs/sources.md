# Источники и границы проекта

- [Задание десятого спринта](https://practicum.yandex.ru/learn/software-architect-pro/courses/3e8bb788-bdd7-49c6-a2ef-d7d1cbc6cd7c/sprints/810691/topics/c8c37c45-1332-4328-aea2-6af130803ecb/lessons/d7fd3107-f2d7-4d96-bcd4-500e3b04b038/).
- [Исходная C4-схема](https://code.s3.yandex.net/software-architect/project10-landscape.drawio.xml).
- [152-ФЗ, публикация Минтруда](https://mintrud.gov.ru/docs/laws/130): категории данных, основания обработки, организационные и технические меры. Для внедрения проверяется действующая редакция, а не только учебный материал.
- [Действующая статья 18 о локализации](https://www.consultant.ru/document/cons_doc_LAW_61801/cbf4e15b7c330f9372e876cdf2bc928bad7950ef/).
- [Разъяснение прокуратуры о врачебной тайне и статье 13 323-ФЗ](https://epp.genproc.gov.ru/ru/proc_35/activity/legal-education/explain/e5889646/).
- [PostgreSQL: Row Security Policies](https://www.postgresql.org/docs/current/ddl-rowsecurity.html): runtime не должен быть владельцем или иметь BYPASSRLS; для владельца существует FORCE ROW LEVEL SECURITY.
- [OpenMetadata: Auto PII Tagging](https://docs.open-metadata.org/v1.11.x/how-to-guides/data-quality-observability/profiler/auto-pii-tagging): классификация по именам столбцов и содержимому образцов; не доказательство полноты распознавания медицинских данных.
- [Apache NiFi User Guide](https://nifi.apache.org/nifi-docs/user-guide.html): очереди, backpressure и provenance.

Это учебное архитектурное предложение. Не заявляю юридическое заключение о соответствии, проведённый аудит клиники, внедрённые сервисы или результаты нагрузочных испытаний. Юридическая проверка сроков/оснований и обследование реальной инфраструктуры указаны как этапы внедрения, а не как действия, которые должна выполнить студентка для сдачи архитектурного задания.

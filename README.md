# Десятый спринт

Проектирование системы для клиники «Медикаменте».

| Задание | Решение |
|---|---|
| 1. Аудит безопасности и DFD | [Анализ и восемь процессов As-Is / To-Be](Task1/analysis.md) |
| 2. Privacy by Design и C4 | [MVP, целевой контекст и контейнеры](Task2/architecture.md) |
| 3. Классификация и защита | [Данные, состояния и реестр средств](Task3/protection.md) |
| 4. Узкие места | [Исикава и рекомендации](Task4/bottlenecks.md) |
| 5. Cutover | [Parallel Run, переключение и откат](Task5/cutover.md) |
| 6. Классификация перед хранилищем | [Контейнеры, правила, качество и масштабирование](Task6/classification.md) |

Редактируемые схемы лежат рядом с текстом в `.drawio`; `.svg` можно открыть без редактора. [Условие и источники](docs/sources.md), [проверки материалов](docs/checks.md).

Это архитектурный проект по учебному описанию. Доступа к реальной клинике не было; гипотезы аудита и целевые показатели отделены от подтверждённых условий. Развёртывание production-системы не входит в задание.

Проверить структуру и локальные ссылки:

```sh
python3 scripts/validate.py
git diff --check
```
